## Standards & Quality Guidelines

- **Genuine Gameplay**: Only use actual screenshots captured from running builds (Web browser or Android device). Do not use simulated mockups or non-functional concept renders.
- **Aspect Ratio**: Keep native device resolution without stretching or distortion.
- **Compression**: Use PNG or optimized WebP format with sharp vector/pixel details.
